\#Store Sales Dashboard



\## Project Overview

This project analyzes Store sales data using Microsoft Excel.



\## Tools Used

\- Microsoft Excel

\- Pivot Tables

\- Pivot Charts

\- Slicers

\- Dashboard Design



\## Dashboard Features

\- Sales vs Orders Analysis

\- Sales by Gender

\- Top 5 States

\- Orders by Channel

\- Orders by Age and Gender

\- Order Status Analysis

\- Interactive Slicers



\## Business Insights

\- Women contribute the majority of sales.

\- Maharashtra generates the highest sales.

\- Amazon is the leading sales channel.

\- Most orders are successfully delivered.
